# 本人可照做的前端 Prototype（U1–U4）操作回饋驗收清單

這份文件提供 CheerC 本人在本機練習環境（`npm run dev:prototype`）中，針對 2026-10-15 操作回饋（U1–U4 批次）逐項驗證的具體操作步驟與預期結果。

- **適用版本**：整合 PR #488 合入 main 後之版本（merge commit `6ae1909639f56aa6d36524406e700554891f6328`）。
- **環境要求**：本機單機練習模式（`npm run dev:prototype`，預設 port 5174），完全隔離於雲端 Firebase，不影響正式帳務。
- **資料保護原則**：全程使用合成範例學員（如「測試甲」、「測試乙」），不使用真實個資，不需附加真實截圖。
- **邊界說明**：本清單為 **前端 Prototype 互動行為定稿之驗收**；Prototype 驗收通過不代表雲端正式後端全部完成（雲端 P08 訂餐、P09a 繳費、P09b 退款等由後端線接續落實）。

---

## 驗收前準備

1. 啟動練習模式：
   ```sh
   npm run dev:prototype
   ```
2. 瀏覽器開啟 `http://127.0.0.1:5174`，確認頂部標題列清楚標註「本機練習」。
3. 進入「F3 今日設定」→「學員管理」上方或危險區域確認可重置／匯出練習快照，建議先點擊「從空白開始」或「重置系統數據」取得乾淨起點。

## 一、U1 顯示設定保存（#10）

| 項目 | 操作步驟 | 預期結果 |
|---|---|---|
| **U1-01** | 進入「F3 今日設定」→「顯示偏好」：將主題切換為「暖色深色」或「冷色」，字體大小切換為「大字」，並關閉「滑鼠 hover 自動選取」。 | 頁面即時變更為所選外觀樣式。 |
| **U1-02** | 切換至「F1 POS櫃台」或「F2 報表」分頁，再切回「F3 今日設定」。 | 畫面樣式維持所選外觀，沒有跳回預設主題與字級。 |
| **U1-03** | 在瀏覽器按下重新整理（F5 或 Cmd+R）。 | 重新載入後，主題、字級與 hover 設定完整保留於 `localStorage`，不遺失。 |
| **U1-04** | 回到 F1 搜尋學員，移動滑鼠經過候選清單。 | 因已停用 hover 選取，滑鼠滑過不會搶走鍵盤高亮焦點。 |

## 四、U2c 開帳金額確認（#3）

| 項目 | 操作步驟 | 預期結果 |
|---|---|---|
| **U2c-01** | 於 F3 點擊「設定今日開帳現金」：若當日未開帳且系統有前日關帳建議金額，輸入與前日完全相同之金額。 | 彈出確認對話框，提示「金額與昨日點算相符」，要求**勾選「我已實際清點」核取方塊後**，確認按鈕方可點擊。 |
| **U2c-02** | 輸入與昨日點算不同之金額（例如差異 $100）。 | 對話框顯示差異提示（如「比昨日結餘多/少 $100」），可直接確認。 |
| **U2c-03** | 測試輸入無昨日資料（如首次開帳）或輸入負數／超額金額（> $20,000）。 | 負數或超過 20,000 元時即時阻擋並顯示中文錯誤提示。 |

## 五、U3 學員編號排序、缺號列與改編號（#7）

| 項目 | 操作步驟 | 預期結果 |
|---|---|---|
| **U3-01** | 進入「F3 今日設定」→「學員管理」，檢視學員清單。 | 清單依學員編號之數值大小升冪排序（`001`, `002`, `005`, `010`...）。 |
| **U3-02** | 檢查清單中的號碼跳號區間（例如只有 `001` 與 `005`）。 | 中間空號自動顯示缺號列，如單號顯示「`002` 尚無人使用」，連續空號合併為「`003–004` 尚無人使用（2 個號碼）」。 |
| **U3-03** | 點擊缺號列上的「使用此號碼新增」按鈕。 | 自動帶起「新增學員」表單，且編號欄位自動預填該缺號代碼。 |
| **U3-04** | 在清單上方搜尋框輸入文字篩選學員。 | 搜尋狀態下自動隱藏所有缺號列，僅呈現符合搜尋條件之學員。 |
| **U3-05** | 將某學員（如 `005`）設為「停用」。 | 該列標記「已停用」，仍占用 `005` 號碼，缺號列不會把 `005` 當作無人使用。 |
| **U3-06** | 點擊停用學員列之「編輯」，修改編號為新號碼（如改為 `009`），輸入改號理由並送出確認。 | 彈出確認框說明歷史紀錄將隨帳戶移轉，確認後改號成功；原 `005` 空出變為缺號列；歷史交易與稽核軌跡正確關聯至 `009`。 |

## 六、U4 學生帳戶餘額退款（#1）

| 項目 | 操作步驟 | 預期結果 |
|---|---|---|
| **U4-01** | 於 F1 搜尋並選取有餘額之學員（如餘額 $300），按 **W** 進入繳費模式。 | 繳費金額右上方出現「**退款**」按鈕；若餘額 <= 0，退款按鈕自動停用（disabled）。 |
| **U4-02** | 點擊「退款」按鈕開啟「退款給學生」對話框。 | 顯示學員姓名、目前餘額，金額預設為全部餘額，提供快捷理由標籤（如「結清離班」、「溢繳退還」）。 |
| **U4-03** | 對話框開啟時，按鍵盤 Q/W/E/F1–F5/方向鍵/Enter。 | 鍵盤快捷鍵被對話框有效攔截，不穿透至背景觸發換頁或下單。 |
| **U4-04** | 理由留空，或輸入超過目前餘額之金額（如輸入 $500）。 | 確認按鈕保持停用，或提示「退款金額不能超過目前餘額」及「請填寫退款理由」。 |
| **U4-05** | 輸入金額 $120，選取理由「結清離班」，點擊「確認退款」。 | 退款成功，學員餘額扣減 $120（變為 $180），畫面上方顯示綠色成功橫幅，並出現「**撤回這筆 (5秒)**」按鈕。 |
| **U4-06** | 在 5 秒內點擊「撤回這筆」按鈕。 | 退款交易立即被撤回，學員餘額即刻復原為 $300，稽核軌跡記錄「送出後立即撤回」。 |
| **U4-07** | 再次執行退款 $120，靜待 5 秒倒數結束。 | 5 秒倒數完畢後，撤回按鈕自動消失，退款正式生效。 |
| **U4-08** | 查看「F2 報表」與 E「付款明細」。 | F2 獨立列出「退款」卡片（`totalRefund: $120`），淨現金依公式 `收現 − 支出 − 退款` 正確計算；E 付款明細列出退款項目與金額 `−$120`。 |
| **U4-09** | 於「F3 今日設定」之學員清單中，直接在已停用學員列上點擊「退款」。 | 停用學員**不需先執行恢復**即可直接辦理退款，手續完成後仍維持停用狀態。 |
